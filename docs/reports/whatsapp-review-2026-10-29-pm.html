2 · Main Router v3: a failed lookup no longer drops the message Fixed, published n8n

same node · the 10-28 agent …1283 incident

Evidence: executions 147985–147994 (10-28 10:08–10:09 UTC). FS - Lookup Pending returned {"error":{"message":"The service is receiving too many requests from you","description":"Quota exceeded."}} (it has continueRegularOutput). With no rows, every run took the "empty bucket" exit, so Business Handler never ran and nobody replied.

Change: if the lookup errored (not just came back empty), the run handles its own message alone instead of bailing. A burst may then be answered in pieces while Firestore is down, but nothing goes unanswered. The Firestore quota cause itself was addressed separately by 37ed7f1 (extract sweep), already merged.

3 · Main Router v3: "עצור / מספיק" gets through the generation lock Fixed, published n8n

node Code - Resolve Route

While a batch is running, the lock holds every message as a "followup" until the batch ends. So a stop word could never reach the intake that sets the cancel flag Check Stop reads, and "stop" only took effect after the last photo. Today the agent wrote "זהו מספיק תודה" at 15:08:57 and 11 more photos still arrived until 15:15:57. Now a message matching the stop pattern skips the lock and goes to the intake.

4 · Image Gen v4: one progress message per batch Fixed, published n8n

D6VSszXZdas4Hqve · version 4156c87c → 8bef6a0e · new node IF — Send Ack?

Business Handler v6 already marks photos 2…N with skip_ack: true, but Send Ack ignored it. In the 7-photo batch (15:21) "עובדת על 7 התמונות ✨ כל אחת תגיע כשהיא מוכנה" went out 7 times, once before each photo. A new IF in front of Send Ack skips it when skip_ack is set. Callers that never set it behave exactly as before.

5 · Backend: polite stops count as stops In PR code

server/property-draft.js STOP_RE + test in server/property-draft.test.js

STOP_RE matched only a bare "מספיק"/"עצור". It now allows filler around the stop word ("זהו מספיק תודה", "די תודה", "עצור!"). Real requests still don't match ("מספיק תמונות לדף", "די יפה"). Takes effect when the intake is deployed from main.
