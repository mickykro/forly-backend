# Seven property template redesigns

Preview concepts authorized by the September 14 critique. Open index.html to compare all seven HTML pages, including a 390px preview. Each page embeds its CSS and JavaScript and uses local assets/. Hebrew RTL; responsive layouts; keyboard-operable controls; native modal image viewer; local-only demo forms.

These are complete review prototypes, not replacements for the production template runtime. Property data, editorial imagery, video-derived stills, and the spatial diagram are explicitly illustrative. No form sends or stores data.
